# Online Coding Practice Platform

## Project Description
The Online Coding Practice Platform is a full-stack web application that allows users to practice coding problems, submit solutions, and track their progress in a competitive environment. The platform is inspired by coding practice systems such as LeetCode and HackerRank, providing an interactive interface where programmers can improve their problem-solving skills.

Users can browse coding problems categorized by difficulty levels, write and submit code using an integrated code editor, and receive instant feedback based on predefined test cases. The platform also includes features like leaderboards, user profiles, and progress tracking to encourage continuous learning and engagement.

The application is built using modern full-stack technologies with a scalable architecture that separates the frontend, backend, and database layers.

---

## Technology Stack

### Frontend
- React.js – For building a dynamic and responsive user interface
- Vite – Fast development environment for React
- Axios – For API communication with the backend
- React Router – For page navigation and routing
- Monaco Editor – Integrated code editor for writing and testing code
- CSS / Tailwind / Bootstrap (optional) – UI styling

### Backend
- Spring Boot – RESTful API development
- Spring Security – Authentication and authorization
- JWT (JSON Web Token) – Secure user authentication
- Spring Data JPA / Hibernate – Database interaction
- REST APIs – Communication between frontend and backend

### Database
- MySQL – Relational database for storing application data

### Development Tools
- Git & GitHub – Version control
- Postman – API testing
- Maven – Dependency management
- Docker (optional) – Containerization

## Features

### User Management
- User registration and login system
- Secure authentication using JWT
- User profile with progress tracking

### Coding Problem Management
- List of coding problems categorized by difficulty
- Problem description with examples and constraints
- Problem tagging (arrays, strings, graphs, etc.)

### Code Submission
- Built-in code editor for writing solutions
- Support for multiple programming languages
- Code submission with automated test case evaluation

### Leaderboard System
- Global ranking based on problems solved
- Score tracking for competitive learning

### Dashboard
- Displays user statistics
- Shows recent submissions and progress
- Highlights daily coding challenges

### Admin Panel
- Add, update, or delete coding problems
- Manage users and submissions
- Monitor platform activity
